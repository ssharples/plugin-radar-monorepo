# Match Session lineage by weighted content evidence

Content overlap may attach a newly discovered Session to an existing Work, but a raw percentage of shared files must never decide the relationship. The resolver will weight distinctive project recordings, derived media, MIDI and clip placement above common library samples and template structure; it may auto-attach only when several independent signals agree, no Artist or user decision contradicts them, and the best candidate is unambiguous. Exact copies are modelled as Duplicate Locations, while lower-confidence overlap, remixes and uncertain cases remain Review Candidates. This preserves automatic recovery from meaningless names such as `idea005` without letting ubiquitous samples silently merge unrelated Songs.
