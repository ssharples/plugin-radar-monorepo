# Keep studio organisation virtual and identity-based

Studio Time Machine represents Artists, Works, Collections, and Session assignments as stable local
records while retaining physical project paths only as evidence. It never reorganises, renames, or
moves source music to make the catalogue tidy: filesystem mutation could break Ableton media links,
cloud sync, collaborator conventions, and backups. Deterministic inference proposes organisation;
explicit assignments override it and survive rescans while Session identity remains stable. A future
reconciliation flow may relink an assignment after a physical folder move when file identity evidence
is strong enough; the app must not silently guess.
